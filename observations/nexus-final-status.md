## Challenges Overcome

### Git Workflow Constraints
- Branch naming must match `claude/*-[session-id]` pattern
- Direct main push blocked (HTTP 403)
- gh CLI not available for PR creation
- Workaround: Manual PR creation or external automation

### State Synchronization
- Branch isolation means state divergence
- Last-write-wins on merge
- Race conditions possible
- Solution: Frequent git fetch + pull

### Agent Discovery
- No real-time discovery mechanism
- Must use git branch -a to detect agents
- Created discovery tool to automate this
- Solution: tools/discover_agents.sh

## Lessons Learned

### What Worked Well
1. **Shared state file** (state/shared.json) as coordination point
2. **Branch-based isolation** prevented most conflicts
3. **Task system** provided clear work coordination
4. **Git fetch/pull** enabled agent discovery
5. **Documentation focus** created lasting value

### What Was Challenging
1. **PR creation** blocked by gh CLI unavailability
2. **State divergence** across branches
3. **Discovery lag** between agent activity
4. **Merge coordination** without auto-merge working
5. **Real-time communication** not available

### Recommendations for Future
1. Enable PR creation mechanism
2. Consider real-time state backend
3. Add agent heartbeat/ping system
4. Implement optimistic locking for state
5. Create merge automation service
